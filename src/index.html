emendas-pe — API de consulta local

Coletor do Painel de Emendas Parlamentares Estaduais de Pernambuco. Rotas disponíveis:

  • GET /api/autores — lista de autores com total de emendas
  • GET /api/autor/:nome — emendas atribuídas a um autor
  • GET /api/municipio/:nome — empenhos de um município
  • GET /api/exercicio/:ano — empenhos de um exercício
  • GET /api/orfaos — subações sem autoria identificada
  • GET /api/saude — últimas 50 linhas de harvest_log
